### ABAP-7 Days Revision


# Day 1: ABAP Fundamentals & Data Dictionary
- ABAP Basics: Data types, Operators, Control structures (Loops, IF, CASE)
- Modularization: Forms, Function Modules, Classes
- Data Dictionary (DDIC): Tables, Views, Data Elements, Domains, Search Helps, Lock Objects
- Hands-on: Create a transparent table, define a foreign key, and create a simple report.
# Day 2: Internal Tables & Performance Optimization
- Internal Tables & Work Areas: Types (Standard, Sorted, Hashed), Operations (Append, Insert,
Modify, Read, Sort)
- Performance Optimization: Avoiding SELECT inside loops, Using FOR ALL ENTRIES, Indexing &
Buffering
- Hands-on: Write a report using internal tables, SORT, and READ TABLE. Optimize a SELECT
query.
# Day 3: ALV Reports & Modularization Techniques
- ALV (ABAP List Viewer): Classic ALV (REUSE_ALV_LIST_DISPLAY,
REUSE_ALV_GRID_DISPLAY), OOPs-based ALV
- Modularization: Function Modules, Classes, Methods, Enhancement techniques (User Exits, BADI,
Enhancement Points)
- Hands-on: Create an ALV report with sorting, filtering, and totals. Implement a simple BADI.
# Day 4: ABAP on HANA & CDS Views
- ABAP on HANA: Open SQL vs. Native SQL, AMDP (ABAP Managed Database Procedures)
- Core Data Services (CDS): Define a CDS view, Associations & Annotations, SQL performance
tuning
- Hands-on: Create a CDS view and use it in an ABAP program. Implement an AMDP method.
# Day 5: Smart Forms, SAP Scripts & IDocs
- Smart Forms & SAP Scripts: Form Layout, Windows, Pages, Driver Programs
- IDocs & Interfaces: Basic IDoc structure, Creating and processing IDocs, ALE configuration basics
- Hands-on: Modify a Smart Form to add a new field. Debug an IDoc processing error.
# Day 6: Object-Oriented ABAP & Enhancements
- OOPs ABAP: Classes, Objects, Methods, Inheritance, Interfaces, Polymorphism
- Enhancements & Exits: BAdIs, Customer Exits, Implicit/Explicit Enhancements
- Hands-on: Create a simple class with attributes and methods. Implement a BAdI in an SAP
standard process.
# Day 7: SAP Workflow & Final Revision
- SAP Workflow Basics: Workflow Builder, Business Objects, Events, Task Creation
- Final Revision: Review key concepts, practice coding, and solve real-world scenarios
- Hands-on: Create a simple workflow triggered by a business event.
